# Project Intelligence

`PROJECT-INTELLIGENCE/` is the authoritative product-intelligence record for the Personal Safety Project Intelligence Workspace.

Governing product doctrine, current implementation state, roadmap boundaries, architecture notes, workflow doctrine, UI doctrine, AI governance, and phase records belong here. Root-level application files may describe how to run or deploy the app, but they must not become competing copies of product doctrine.

## Authoritative Records

- `PRODUCT-DOCTRINE.md`: governing product truth and boundaries.
- `DECISIONS.md`: approved baseline decisions and proposed changes.
- `CURRENT-STATE.md`: implementation and planning status.
- `ROADMAP.md`: bounded delivery sequence.
- `architecture/`: implementation and deployment architecture notes.
- `phases/`: phase-specific implementation status and closure records.

Operating rule: document proposed behavior changes before implementation. Preserve evidence, provenance, and human authority.
