# Workbench UI

Status: Approved UI refinement direction for Pass 1. This is not Phase 9.

## Role

The Workbench is the action surface: upload, create, edit, review, generate, confirm, reject, and manage workflow-specific records.

## Boundaries

Workbench refinements must preserve all existing domain behavior and confirmation rules. Presentation may change; authority, provenance, validation, and persistence behavior must not.

## Interaction Direction

- Group related tools into compact sections.
- Keep action buttons visually distinct from read-only context.
- Make pending work, active selections, and proposed actions easy to scan.
- Keep touch targets usable on tablet.
- Do not hide mandatory fields required for existing workflow completion.

## Relationship to Assistant

The Assistant may explain, draft, or propose; the Workbench is where the user performs authenticated operational work and human confirmation.
