# Visual System

Status: Approved UI refinement direction for Pass 1. This is not Phase 9.

## Direction

The visual personality should align with a modern SafetySync/GitHub-inspired professional workspace:

- dark,
- restrained,
- tech-forward,
- high readability,
- subtle cyan/blue accents,
- strong information hierarchy.

Avoid marketing-style hero treatment inside the authenticated app. The first screen should remain the usable workspace.

## Core Treatment

- Dark application background.
- Panels with subtle borders and quiet elevation.
- Compact rows for repeated records.
- Cyan/blue accent for active state and primary actions.
- Warm/destructive color only for errors or attention.
- Preserve readable contrast for long safety records, source chunks, reports, and assistant messages.

## Components

Use existing controls and semantics. Refinement should focus on layout, spacing, hierarchy, and color rather than introducing new business interactions.

Buttons should distinguish:

- primary action,
- secondary action,
- ghost/supporting action,
- selected row/action.

Cards are appropriate for repeated items, details, modals, and tool sections. Do not turn every page section into decorative nested cards.
