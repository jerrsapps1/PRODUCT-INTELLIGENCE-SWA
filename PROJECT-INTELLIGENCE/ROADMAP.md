# Phased Roadmap

| Phase | Scope | Exit condition |
|---|---|---|
| 1 - Foundation | App shell, responsive/PWA, auth, database, storage abstraction, projects, contractors. | Formally complete: a private user can create/open blank projects, manage contractor records/engagements, and navigate the three-panel workspace on desktop and iPad. |
| 2 - Source Intelligence | Uploads, library, extraction/indexing, authority, retrieval, citations. | Formally complete: sources retain classification, provenance, project activation, and citation-ready retrieval. |
| 3 - Contractor Readiness | GC policy, requirements, evidence, EMR/TRIR. | Formally complete: readiness is policy-driven, evidence-backed, and human-reviewed. |
| 4 - Plan Review | Plan ingestion, review, findings, side-by-side UX, editable recommendations, revisions. | Implemented for review: human reviewer can produce cited, editable reviews and approve pending plans. |
| 5 - Field Operations | Observations, photos, AI categorization, contractor linkage. | Touch-first observations are preserved and optionally enriched by editable AI proposals. |
| 6 - Incident Oversight | Contractor incident intake, GC/project review, decisions, follow-up. | Contractor evidence and GC oversight remain explicitly separate. |
| 7 - Reporting | Daily/weekly/monthly/custom reports and editable artifacts. | Evidence-grounded reports are generated, edited, and finalized. |
| 8 - Memory and Skills | Approved memory, decision promotion, guided skill management, Markdown editing. | Long-term operational memory remains human-approved and inspectable. |
| 9 - Historical Intelligence | Closeout, historical retrieval, future-selection summaries. | Project history informs human contractor-selection judgment without black-box scores. |

Every phase must satisfy the full-stack completion checklist before it closes.
